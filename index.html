Tugas Pertemuan 6 — Pemrograman Web (Operator PHP)

Ringkasan studi kasus penggunaan operator di bahasa PHP pada repository tugas-php-pertemuan-6.

Catatan: GitHub Pages hanya menyajikan berkas statis (HTML/CSS/JS) dan tidak menjalankan kode PHP secara langsung. Klik tombol pada tiap kartu untuk melihat kode sumber di GitHub, lalu jalankan file .php di server lokal (seperti XAMPP/Laragon) untuk melihat hasil eksekusi.

Studi Kasus 1: Sistem Pembelian di Toko Online

Aritmatika, =, >=, &&

Menghitung total belanja 4 produk (Rp150.000/item), menerapkan diskon 10% jika total awal minimal Rp500.000, memberikan voucher Rp25.000 jika berstatus member dan setelah diskon minimal Rp400.000, lalu menambahkan ongkos kirim Rp15.000.

Buka studi_kasus_1.php

Studi Kasus 2: Sistem Saldo E-Wallet

+=, -=, ++

Menyimulasikan mutasi saldo awal Rp500.000 untuk top up (Rp200.000), bayar tagihan (Rp125.000), beli makanan (Rp75.000), dan cashback makanan (Rp10.000) sambil menghitung total transaksi.

Buka studi_kasus_2.php

Studi Kasus 3: Sistem Penentuan Tarif Parkir

/, %, >, <=, ? :

Membulatkan durasi menit ke atas menjadi jam menggunakan pembagian dan modulus (%), menghitung tarif (Rp5.000 untuk 2 jam pertama dan Rp3.000/jam berikutnya), serta membatasi maksimal Rp35.000 jika durasi lebih dari 12 jam memakai operator ternary dengan data uji 90, 185, dan 780 menit.

Buka studi_kasus_3.php
