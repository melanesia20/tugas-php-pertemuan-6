# Tugas Pertemuan 6 - Pemrograman Web (Operator PHP)

Repository ini berisi kode program PHP untuk menyelesaikan tiga studi kasus penggunaan operator pada bahasa PHP:

1. **`studi_kasus_1.php`** — Sistem Pembelian di Toko Online (operator aritmatika, penugasan, perbandingan `>=`, dan logika `&&`).
2. **`studi_kasus_2.php`** — Sistem Saldo E-Wallet (operator penugasan gabungan `+=`, `-=`, dan increment `++`).
3. **`studi_kasus_3.php`** — Sistem Penentuan Tarif Parkir (pembagian, modulus `%`, perbandingan, dan operator ternary `? :` dengan data uji 90, 185, dan 780 menit).
